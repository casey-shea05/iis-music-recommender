# Shortlist: five verified sources

## Screening criteria (written before screening)
1. Concerns a recommender system, with a preference for music but accepting comparable domains (e.g. film, news, social recommenders), since the findings on control and explanation are expected to transfer.
2. Addresses at least one of: user control or feedback over recommendations, or explanations/transparency about why items are recommended.
3. Is user-facing: it involves a user study, survey or interface design and looks at how people experience the system, rather than only improving model accuracy or offline performance.

| Putting Users in Control of their Recommendations | `in` | Study of basic recommender systems (all criteria covered) |
| Music Recommendation Systems … and How They Want to be Used | `in` | Qualitative user study of music recommendation features (1, 3); finds satisfaction depends on perceived controllability and users want tools to influence recommendations (2) |

| Explore, exploit, and explain: personalizing explainable recommendations with bandits | `flagged` | Music recommender with explanations (meets 1, 2) and live user testing, but the contribution is algorithmic and it measures engagement, not users' experience or sense of control (borderline on 3) |
| A Live Concert Performance Recommender System Utilizing User Ideal and Antithesis Ideal Setlist Preferences | `in` | Music-domain recommender that combines user control via ideal/negative setlist preferences with explanations of recommendations (covers all 3 criteria) |
| What's in a User? Towards Personalising Transparency for Music Recommender Interfaces | `in` | Music recommender user study (1, 3) testing how explanations affect perception and gaze (2); personality is a moderator, so it shows who benefits most from explanations |
| Controlling Spotify Recommendations: Effects of Personal Characteristics on Music Recommender User Interfaces | `in` | Directly tests user control over music recommendations, alongside investigating how musical sophistication plays a role in the interactions of these systems (covers all 3 criteria)  |
| What Makes an Explanation Good: A Systematic Review Examining Recommender System Explanations from User Perspective | `in` | Systematic review on how to design good explanations in recommender systems based on user opinions |
| The effects of controllability and explainability in a social recommender system  | `in` | Investigates the effects of adding user control and visual explanations in a specific context of an interactive hybrid social recommender system|
| Explanations and user control in recommender systems. Personalized Human–Computer Interaction | `in` | Chapter reviews explainations and feedback mechanisms as a means of building trustworthy recommendation systems|
| Effects of personal characteristics in control-oriented user interfaces for music recommender systems | `in` | Music recommendation system study on user controls and how people respond to them |
